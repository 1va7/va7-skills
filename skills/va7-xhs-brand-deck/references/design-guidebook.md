# Yibi Design Guidebook Summary

Use this as the default visual language for the partner deck.

## Tokens

- Paper: `#F1EFE8`; secondary paper: `#E7E3D6`
- Ink: `#1F1C18`; secondary ink: `#3A352E`
- Muted text: `#5C564C` / `#9B948A`
- Rule: `#CCC6B5`; soft rule: `#DCD6C4`
- Primary accent: `#DC580E`
- Restrained secondary accent: `#A07020`
- Dark cover: `#171A1A`

## Typography

- Chinese display: Noto Serif SC / Songti SC, weight 700 where available.
- Body: Inter, 500–600.
- Metadata: JetBrains Mono, uppercase English labels, generous letter spacing.
- Optional English italic: Cormorant Garamond.

## Composition

- Fixed 16:9 stage, editorial newspaper rhythm, generous whitespace.
- Start sections with an orange hairline/kicker and a concise dateline.
- Prefer one strong conclusion per slide, thin rules, square or low-radius panels, and restrained cards.
- Highlight only a word or short phrase in orange; do not color entire paragraphs.
- Use source labels and data boundaries as part of the visual system.
- Avoid purple gradients, generic dashboard layouts, excessive rounded pills, and unsupported premium/wealth claims.
