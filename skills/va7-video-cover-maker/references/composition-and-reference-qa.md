# VA7 封面构图与历史对照 QA

## 核心定义

“保留底图原貌”只表示保留真人身份、表情、环境、光线和色彩，不重绘、不换背景、不做生成式人物修改。它不表示沿用原图构图。

封面必须通过裁切、缩放和取景平移重新建立构图。原图即使已经是 16:9，也不能因为输出同为 16:9 就直接使用全画幅。

## 构图优先级

按以下顺序判断：

1. 先匹配同类历史成品中人物的位置和占比。
2. 再保证标题区与人物区清晰分离。
3. 再调整背景取舍。
4. 最后微调字体、阴影和颜色。

不要先把文字塞进原图剩余空间，再把结果称为封面设计。

## 默认人物构图区间

以下区间来自本地专业知识类成品，作为起始范围，不替代逐图视觉判断：

| 比例 | 人物构图起点 |
|---|---|
| 16:9 | 人脸视觉中心通常位于画面宽度约 58%-70%；头顶接近上边缘，默认控制在 2%-8%；人物应形成右侧主视觉，而不是居中站立。 |
| 4:3 | 人脸视觉中心通常位于约 62%-75%；人物比 16:9 更大；头顶默认不超过 15%；左侧保留完整标题列。 |
| 3:4 | 人物明显放大并被右边缘主动截断；眼睛、鼻梁和嘴部仍完整可读；头顶约 0%-8%；不要把完整半身缩在竖版中央。 |

这些百分比是视觉锚点，不要求依赖自动人脸检测。最终以同类历史成品对照板为准。

## 已确认默认基准：0713 Skills Sync v3

用户已明确确认 `0713 Skills Sync v3` 的人物位置、人物比例和裁切正确。今后没有其他指定参考时，把 [0713 Skills Sync 构图预览](<assets>/cover-case-library/local-previews/0713-skills-sync-approved-composition-preview.jpg) 作为默认人物构图基准，并将它放入历史 QA 对照板。

原始底图为 `3840×2160`，已确认 crop 与归一化位置如下。绝对坐标只适用于该底图；迁移到其他图片时匹配归一化构图和视觉效果，不要照抄像素值。

| 比例 | 已确认 crop | 源图归一化 crop | 头顶比例 |
|---|---|---|---|
| 16:9 | `[0, 360, 3200, 2160]` | `[0.000, 0.167, 0.833, 1.000]` | 约 `0.02` |
| 4:3 | `[0, 90, 2760, 2160]` | `[0.000, 0.042, 0.719, 1.000]` | 约 `0.14` |
| 3:4 | `[650, 360, 2000, 2160]` | `[0.169, 0.167, 0.521, 1.000]` | 约 `0.01` |

该基准的关键视觉结果：16:9 人物放大并右置、头顶贴近上沿；4:3 保留较完整上半身但仍以人物为右侧主视觉；3:4 明显放大并由右边缘主动截断，眼睛、鼻和嘴保持可读。

## 已确认主副标题布局基准：0713 Skills Sync v4

使用 [0713 Skills Sync v4 已确认布局预览](<assets>/cover-case-library/local-previews/0713-skills-sync-approved-layout-preview.jpg) 作为主副标题位置、字号和留白的默认成品参考。

主标题和副标题必须被当作两个独立的信息区，而不是沿着左边缘随意堆放：

- 主标题固定在左上内容区，承担第一视觉层级。
- 副标题固定在左下内容区，承担三条内容目录；不要紧跟在主标题下面。
- 副标题左边距应等于或略大于主标题左边距，让左侧形成稳定的纵向留白。
- 主标题与副标题都不得覆盖头发、眼镜、眼睛、鼻、嘴或面部轮廓。
- 不要为了避脸把文字重新推回画布边缘；应先保持安全 padding，再微调字号或断行。

v4 已确认参数及归一化位置：

| 比例 | 主标题 xy / 字号 | 主标题归一化位置 | 副标题 xy / 字号 | 副标题归一化位置 |
|---|---|---|---|---|
| 16:9 | `[115,105]` / `240` | `[0.030,0.049]` | `[130,1435]` / `152` | `[0.034,0.664]` |
| 4:3 | `[95,100]` / `214` | `[0.033,0.046]` | `[108,1440]` / `136` | `[0.038,0.667]` |
| 3:4 | `[100,105]` / `214` | `[0.062,0.049]` | `[110,1415]` / `138` | `[0.068,0.655]` |

迁移到其他封面时使用以下默认区间：

- 主标题顶部：画布高度的 `4%-10%`。
- 副标题顶部：画布高度的 `58%-72%`。
- 主标题单行字号：画布高度的 `8.5%-13%`。
- 副标题字号：画布高度的 `5.5%-8%`。
- 16:9 / 4:3 主标题左 padding 至少 `2.5%`，副标题至少 `3%`。
- 3:4 主标题左 padding 至少 `5%`，副标题至少 `6%`。

## 3:4 文字安全内边距

在已确认人物 crop 不变的前提下，文字不要贴左上边缘：

- 主标题左 padding 默认至少为画布宽度的 `5%`，顶部 padding 至少为画布高度的 `4%`。
- 副标题左 padding 默认至少为画布宽度的 `6%`。
- 增加 padding 后仍须保证标题最右侧与头发、眼镜和面部轮廓之间存在清晰间隔。
- 文字位置应通过移动 `xy` 调整，不得为了腾位置改变已确认的人物 crop。

## 强制裁切规则

- 为 `16x9`、`4x3`、`3x4` 分别填写显式 `crop: [left, top, right, bottom]`。
- 禁止在正式布局中使用 `crop: null`、省略 `crop` 或依赖自动居中裁切。
- 允许 16:9 使用小于原图的 16:9 crop，以同时完成放大和水平重定位。
- 保证 crop 的宽高比与目标比例一致；不要依赖渲染器把错误比例强行拉伸。
- 优先裁掉人物背后的冗余背景，不要裁掉文字区所需的负空间。
- 为每个比例独立调 crop；禁止从一个比例按数学中心机械换算另外两个比例。

## 历史参考选择

正式渲染前，从 `cover-case-library/index.md` 选择至少两组、最好三组同类型成品：

- 内容类型相同：专业知识类优先对照专业知识类。
- 文案结构相近：核心概念 + 三个要点优先对照 `Skill2Loop`、`Loop Engineering`。
- 人物拍摄环境相近：户外自拍优先对照户外自拍。
- 每组参考必须包含同一成品的 16:9、4:3、3:4 预览，不能只看一张 4:3 发布图。

## 强制 QA 顺序

1. 渲染三比例草稿与当前 preview。
2. 使用 `../va7-cover-tools/scripts/build_reference_qa_board.py`，把当前 preview 放在第一行，至少两组历史 preview 放在下面。
3. 打开 QA 对照板，不允许只看当前 preview。
4. 对每个比例逐项检查：
   - `subject_position`：人物是否处于参考图一致的右侧位置。
   - `subject_scale`：头脸占比是否接近参考，而不是人物过小或过大。
   - `head_top_margin`：头顶距上边缘是否接近参考。
   - `text_hierarchy`：主标题和副标题尺寸是否接近同类封面。
   - `text_subject_separation`：文字是否有独立列，未侵入眼镜、眼睛、鼻、嘴。
   - `reference_match`：缩略图第一眼是否属于同一套 VA7 封面系统。
5. 任一项为 false，修改 crop 或排版并重新生成整个 QA 对照板。
6. 所有比例通过后，写入 visual-review JSON，再运行严格 QA。

同时填写 `head_top_fraction_estimate`。按“画布顶部到头发最高点的距离 / 画布高度”估算。16:9 与 3:4 默认必须位于 `0.00-0.08`，4:3 不超过 `0.15`。人物仍显得靠下时，继续增大 crop 的 top 值，把人物向上移动；不要只移动文字。

主标题还要通过布局级尺寸检查：两行主标题的 `font_size × 行数 / 画布高度`，16:9 与 4:3 默认至少 `0.16`，3:4 默认至少 `0.18`。这只是防止明显偏小的下限，最终仍需看历史对照板。

`qa_cover_set.py` 默认执行严格 QA。`--dimensions-only` 仅用于诊断文件和尺寸，不能作为最终交付依据。

## 对照板命令

```bash
python3 ../va7-cover-tools/scripts/build_reference_qa_board.py \
  --current "$COVER_DIR/${PREFIX}_preview.jpg" \
  --reference <assets>/cover-case-library/local-previews/0704-skill2loop-preview.jpg \
  --reference <assets>/cover-case-library/local-previews/0623-loop-engineering-preview.jpg \
  --reference <assets>/cover-case-library/local-previews/0708-fde-timing-preview.jpg \
  --out "$COVER_DIR/${PREFIX}_reference_qa.jpg"
```

## Visual Review JSON

每个比例必须填写全部六项。`notes` 要说明与参考相比的人物位置和占比，不能只写 `looks good`。

```json
{
  "references": ["0704-skill2loop", "0623-loop-engineering", "0708-fde-timing"],
  "specs": {
    "16x9": {
      "subject_position": true,
      "subject_scale": true,
      "head_top_margin": true,
      "head_top_fraction_estimate": 0.05,
      "text_hierarchy": true,
      "text_subject_separation": true,
      "reference_match": true,
      "notes": "人物右置并放大，头顶距离与 Skill2Loop/FDE 接近。"
    },
    "4x3": {},
    "3x4": {}
  }
}
```

## 失败条件

出现以下任一情况，不得向用户交付：

- QA 只检查像素尺寸和文件存在。
- 当前成品没有与历史成品出现在同一张对照板中。
- 16:9 因为与源图比例相同而跳过重新构图。
- 三比例共用同一个自动中心裁切逻辑。
- 人物位于画面中间，左侧和右侧都留有大量无效背景。
- 竖版头顶明显低于参考，或人物完整缩在画面中。
- 文字尺寸只按画布比例缩放，没有按缩略图效果重新调整。
- 3:4 主标题或副标题贴近左边缘，未达到已确认的安全内边距。
- 副标题与主标题挤在同一垂直区域，或副标题左边距小于主标题。
- 主副标题字号明显偏离 v4 的归一化比例。
