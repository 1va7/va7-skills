# VA7 封面文案规律

这份参考只处理封面文案的语义结构。字体、颜色、裁切和版式规则见 `va7-cover-style.md`；历史成品见 `cover-case-library/index.md`。

## 先判断内容类型

写文案前，先读取灵感库中的 `选题类型`。没有明确字段时，再根据口播终稿判断。

- `专业性` / 专业知识类：默认类型。主标题给出核心知识关键词、概念、框架或关键问题；副标题用 3-4 个 bullet points 展开最重要的论点或机制。
- `故事线` / 观点表达类：例外类型。允许主标题表达判断、冲突或故事钩子，副标题可补充适用人群、情境或结论。
- 无法确定时，按专业知识类处理，不要因为一句有冲突感的话就改成观点封面。

历史样本中，有封面的 15 条成品里 14 条为专业性、1 条为故事线。因此，观点表达式标题不是 VA7 封面的通用默认。

## 专业知识类默认结构

### 主标题：核心知识关键词或概念

主标题要让观众一眼知道这条内容讲的知识对象是什么。优先选择：

- 新概念或方法名：`Loop Engineering`、`Agentic FDE`
- 关键机制或阶段变化：`从 Skill 到 Loop`、`Skill 反向进化`
- 明确的框架或比较：`FDE vs 内部培训`、`企业 AI 转型三个坑`
- 有证据支撑的核心问题：`AI 转型到底多烧钱？`

主标题可以带必要的证据、数量或语境，但核心概念必须仍然清楚。不要只写一句情绪化结论，让用户看不出视频究竟讲什么。

### 副标题：3-4 个核心 bullet points

副标题不是广告口号，而是内容目录。选出口播中最重要的 3-4 个机制、论点、步骤或比较维度。

每个 bullet 应满足：

- 短：通常 2-8 个汉字或一个简短英文术语。
- 平行：统一使用名词短语或动宾短语。
- 独立：彼此覆盖不同信息，不重复改写同一点。
- 核心：删掉任意一条都会损失内容结构，而不是只损失修辞。
- 可扫读：缩略图尺寸下不需要读完整句子。

常见平行结构：

- 三个机制：`捕获改动 / 审核改动 / 沉淀版本`
- 三个能力：`可追溯 / 可评估 / 可自进化`
- 三个步骤：`记录反馈 / 复盘归因 / 人审迭代`
- 三个问题：`问题类型错配 / 迭代速度 / 项目制验证`
- 三个比较维度：`记忆系统 / 多 Agents 架构 / 主动学习 / 消息队列`

通常选 3 条；当第四条是独立且必要的核心机制时使用 4 条。不要为了凑数添加弱信息。

## 历史中允许的专业类变体

专业知识类不要求机械地全部做成 bullet，但偏离默认结构需要有明确原因：

- 概念 + 承诺：`Agentic FDE` + `用 AI 打造会自我进化的公司`
- 样本 + 证据：`AI 转型到底多烧钱？` + `3类不同公司 / 真实 token 账单`
- 对比或访谈：`FDE vs 内部培训`，主标题已经完整表达结构时可以不加副标题。
- 论点 + 框架：`先别找 FDE` + `AI 转型两阶段 / 从组织提效 / 到个人提效`

这些是有依据的变体，不应取代“核心概念 + 3-4 个论点”的默认格式。

## 故事线 / 观点表达类例外

历史案例 `买英伟达 / 不如 / 投自己` 属于 `故事线`。它用冲突性观点做主标题，以 `早期 / 创业者 / 别分心` 补充对象与结论。这种写法适合个人判断、创业叙事或价值观表达，不适合作为专业知识内容的模板。

## 反例

- 用口号占掉副标题：`不是 Agent 变笨 / 是迭代失控` 有冲突感，但隐藏了视频真正提供的三个方法。
- 主副标题重复：主标题说“Skill 版本管理”，副标题又写“管理 Skill 版本”。
- bullet 语法不平行：`捕获改动 / 为什么要审核 / Git 仓库很重要`。
- 把背景数字当成知识核心：`平均 126 个 Skills` 是证据，不是这条内容的核心概念。
- 为了吸睛抹掉主题：只写 `越改越差`，观众无法判断讲的是 Skill、Agent 还是组织管理。

## 文案选择流程

1. 读取 `选题类型`、口播终稿和已确认的视频标题。
2. 用一句话写出“这条视频教会观众的核心概念是什么”。
3. 从正文抽取 5-7 个候选机制、论点或步骤。
4. 合并重叠项，选出 3-4 个最独立、最核心的点。
5. 把各项改成平行短语，并检查缩略图可读性。
6. 对照 `cover-case-library/index.md` 中同类案例，而不是跨类型套用特殊案例。
7. 给用户 2-4 组候选时，默认至少一组严格采用专业知识类结构。

## Skills Sync 当前案例

口播核心问题是 Skill 在无系统 Evaluation 和版本管理时发生“局部进化、全局退化”，最终给出的最小闭环是捕获、审核、沉淀。

推荐封面文案：

```text
主标题
Skill
反向进化

副标题
捕获改动
审核改动
沉淀版本
```

这里主标题保留最核心的新概念，副标题直接呈现视频最有用的三个动作。`Evaluation` 是重要前提，但正文明确说本条不展开，因此不占用本期封面的三个核心 bullet。
