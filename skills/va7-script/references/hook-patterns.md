# 勾子套路

这些是可选写法，按当前题目和真实素材选择。问题型、反共识型、共识后的未解问题同样可用；《一号位》《防止 skill 越改越差》不需要被改成数字事件开头。写到观众理解相关性和张力后进入正文，不固定三句、时长或数字。用户明确选择的开头优先。

## 弱勾子 vs 强勾子

### 弱勾子（会让人划走）

> 很多人觉得 OpenClaw 只能当生活助理，在企业生产中干不了活。
> 但说实话，那是你没用对。

**问题：**
1. 不关心 OpenClaw 的人直接划走
2. "又是夸大其词的视频"
3. "没觉得不能在企业干活啊"
4. 被否定的感觉（"你没用对？"）

### 强勾子（让人想看下去）

> 这周我们烧了7亿多的token，大概是一千多美金。但是我觉得很值，因为我们终于搞明白了怎么去管理一个 AI Agents 团队。如果你是一人公司，或者想用 AI 来管理团队协作，那请看完这条视频，我们已经帮你省下 1000 美金的学费。

**为什么强：**
- 具体数字（7亿 token、1000 美金）
- 所有人都关心钱
- "帮你省下学费"= 价值承诺

## 强勾子公式

### 公式1：具体数字 + 价值承诺

> [具体数字] + [我学到了什么] + [你能省下什么]

**示例：**
> 这一周，我烧掉了 7 亿个 token，换算成钱大概 1000 多美金。但我觉得值，因为我终于搞明白了怎么把 AI agent 从"玩具"变成"员工"。如果你正在考虑用 AI 来帮你干活，这篇内容可以帮你省下这 1000 美金的学费。

### 公式2：装逼 + 反转

> [装逼的数字/成就] + [但是...] + [真正的价值]

**示例：**
> 最近有个100万的合同要续签。去年一直合作的律所，说8折，按8000块工时费帮我审。但作为一个一人公司的创业者，本着能AI尽AI的原则，我先做了一个OpenClaw的session，让AI帮我初审一下……

### 公式3：痛点共鸣 + 解决方案

> [大家都有的痛点] + [我找到了解决方案]

**示例：**
> 你有没有这种感觉：AI 工具用了一堆，但总觉得它们只能做一些"玩具级"的事情？我之前也这么觉得，直到这一周，我终于搞明白了问题出在哪里。

## VA7 钩子三句式（ABC 结构，可选）

当真实亲历和价值承诺适合本题时，可以用以下三个功能组织开头；功能不必各占一句：

### 结构

```
A句（专业性背书）→ B句（吊胃口）→ C句（价值承诺）
```

### A句：专业性背书

**作用**：增强信任。VA7 目前粉丝量还在增长期，需要在内容上突出专业性。

**写法**：用具体数字 + 具体事件证明"我有资格讲这个话题"。

**已验证的模式：**
- "上周给100个跨境卖家做openclaw的培训和部署"
- "这周给十几个客户做OpenClaw的部署和培训"
- "我们最近烧了15亿的token在OpenClaw上"
- "这周我们烧了10亿多的token在OpenClaw上"
- "刚从亚马逊总部的闭门AI讨论会回来"

**关键**：事件与数字需要真实依据；没有数字不影响使用其他开头。不能编造经历来填模板，也不要用"我研究AI很多年"代替可信内容。

### B句：吊胃口

**作用**：制造认知缺口，触发反直觉/FOMO/好奇心/恐惧情绪，让人"不看下去就难受"。

**已验证的模式：**
- 反直觉："你们猜现场有多少个人此前是用过Agent的？"（答案是零）
- FOMO/痛点共鸣："你们的OpenClaw是不是还搞不定长任务和复杂任务？"
- 情绪转折："但是感觉越来越离不开了"
- 反直觉+价值："大概就是1500美金吧。但是我觉得非常值啊，因为我们终于figure out怎么去管理一个AI agents团队"

**关键**：B句要打人性（钱/恐惧/好奇/FOMO），不是打概念。小众概念不适合做B句（需要解释=冷启动=高跳出率）。

### C句：价值承诺

**作用**：告诉观众"看完这条视频你能得到什么"，激励观众继续看。

**已验证的模式：**
- 直接承诺："具体的解决方案在评论区。但接下来我想跟大家详细分享一下，我们解决了这个问题一共有三层的不同的思路"
- 框架预告："我们具体在落地当中是怎么去配置这些多agents的，今天就来跟大家详细分享一下"
- 省钱/省时间："如果你是一个一人公司，或者你想要AI来管理协调你的整个团队的话呢，那请看完这条视频，因为我们已经帮你省下了1500刀的学费"

**关键**：C句要给出具体的价值（框架/方法/省多少钱），不能只说"今天来聊一聊"。

### 检查清单

使用ABC时检查背书是否有依据、张力是否与受众相关、价值承诺是否由正文兑现。所有开头都检查：
- [ ] 观众能理解具体问题，以及为何与自己有关吗？
- [ ] 是否为了抓人加入无来源的数字、经历或夸张立场？
- [ ] 若承诺回答若干问题，正文是否逐一回答？
- [ ] 是否把内部分析框架误作成片目录？
- [ ] 开头是否重复解释了正文即将展开的内容？

## 勾子类型框架

| 类型 | 尝试实现的作用 | 例子 |
|------|------|------|
| 专业度证明型 | 提供可信的实践背景 | 博士、烧了10亿token |
| 故事/问题唤醒型 | 让观众关心一个待回答的问题 | "猜猜今年哪个资产涨的最好" |

**结合公式：** [身份/成就背书] + [反直觉发现/未解之谜]

**示例：** "烧了 10 亿 token 后，我发现了一个让我后背发凉的规律..."
